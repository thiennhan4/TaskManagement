# Naming Rules

## Interface
- Prefix with I
- Example: IUserService

## Async methods
- Must end with Async
- Example: GetByIdAsync()

## DTO
- Suffix with Dto
- Example:
  - CreateTaskDto
  - TaskResponseDto

## Repository
- Suffix with Repository

## Service
- Suffix with Service

## Entity
- Singular noun
- Example:
  - User
  - TaskItem
  - Board
